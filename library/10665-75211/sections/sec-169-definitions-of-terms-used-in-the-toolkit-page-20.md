4.4	 Define target measures for eHealth outcome indicators
Objective
This step defines targets for each eHealth outcome indicator across the previously-defined 
timeframes. These targets allow the evaluation of the results for stakeholders. 
The targets set for the eHealth outcome indicators should accurately reflect the results that can 
be realized given the target rates of eHealth adoption. Targets should be ambitious but realistic. 
Recommended outputs
This step should produce a set of targets for each eHealth outcome indicator across the 
previously defined timeframes (Table 7).
