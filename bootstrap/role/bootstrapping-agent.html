https://litlfred.github.io/who-iris/bootstrap/role/bootstrapping-agent · bootstrap:Role · JSON-LD · part of bootstrap.jsonld

labelBootstrapping Agent
descriptionAn agent asked to set up a Harness with ONLY the knowledge bootstrap's README.md hands it. That constraint is the role, not a caveat on it: a Bootstrapping Agent has no MCP server, no harness, no work plan and no skills beyond those bootstrap carries, and a step that assumes any of those is a step a Bootstrapping Agent cannot perform. It stops being a Bootstrapping Agent the moment the harness is installed and it re-enters through that harness instead.
