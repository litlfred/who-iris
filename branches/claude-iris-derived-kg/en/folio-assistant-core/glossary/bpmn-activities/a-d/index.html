Answer the other four gates candidate, extracted

Restrictions, copyright, retention and source loss, each answered permitted, refused or unknown. They are four answers to one decision, and Gateway_Gates reads them with size through decisions/materialization-gate.dmn. RESTRICTIONS. 'No restrictions known in context' is a STATE, not a green light. GateVerdict is three-valued for this reason alone, and unknown is never rendered as permitted. COPYRIGHT. What the licence permits for THIS bitstream, and separately whether it permits the derivation. LICENSE-CONTENT.md exists in this repository and the ingestion pipeline does not read it. RETENTION. A copy with no expiry cannot be told from an abandoned one — the same argument bean-blocking makes about a block with no expiry. An ARCHIVAL copy is the exception and it is a specification rather than an omission: freshness() reports it permanent, not no-expiry. SOURCE LOSS. Not hypothetical. The one IRIS record this repository holds carries a handle on iris.wpro.who.int, a regional instance merged into the global one. Only an ARCHIVAL copy of the original bytes discharges this; a working copy cannot, because the derived sections are not the publication.
