namePublish extracted statements with source links
summaryMakes every statement extracted from a library source readable, with a link back to where it came from, in the folio's working artifact AND in the shared extraction viewer, and keeps the pages current.
descriptionMakes every statement extracted from a library source readable, with a link back to where it came from, in the folio's working artifact AND in the shared extraction viewer, and keeps the pages current. ONE SUB-PROCESS, CALLED FROM EVERY PROCESS THAT ADDS SOURCE DOCUMENTS TO A FOLIO'S WORKING ARTIFACT. Ingestion calls it when an entry is promoted; an authoring process calls it when it brings a further source into its artifact. Nothing here depends on the content type: a document, a paper, an implementation guide and a guideline all run the same four steps. What differs is how the artifact's pages look, and that is the content type's adapter's business, read off its content profile, never named here. WHAT A STATEMENT IS, for this process: a sentence or row captured verbatim from a library entry, whatever kind the extraction gave it (a recommendation, a requirement, a candidate still awaiting a person's ruling). It is published as captured, with its status; this process neither promotes nor edits it.
