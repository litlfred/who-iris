descriptionReviewer comments on a folio's edit-set, from a tagged pull-request comment to a structured todo on the review page. Use when a reviewer asks how to comment on a block, when the review page shows no comments or a wrong one, when editing the ingestion, or when a folio's staging workflow is set up.
