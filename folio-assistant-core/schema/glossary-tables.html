Description

folio-glossary-tables/v1: which document blocks show which glossary as a table, read by the Tool glossary-table (scripts/glossary-table.ts).

{ "$schema": "folio-glossary-tables/v1",
  "tables": [{ "glossary": "glossary/x.glossary.json", "block": "folio/doc/glossary/t.md", "kind": "terms" }] }

Paths are relative to the layer root. The file lives at <instance>/glossary/glossary-tables.json, inside the glossary kind's directory, so the kind lists this family beside folio-glossary/v1 (typologies/glossary.json) and validators/glossary-tables.json names this schema as its validator. It lives here, not in the script, so a validator node can name it the way every other one names a schemas/ file.
