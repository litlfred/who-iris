nameGitHub connector (host-provided)
descriptionAbility to reach the forge through a connector the HOST supplies — an MCP server the agent did not configure and cannot inspect. DISTINCT FROM github-api: the agent holds no credential of its own, so what it may do is whatever the connector was granted, and that is knowable only by trying. An mcp-probe against the server is therefore the honest detection: it answers 'is the connector reachable', which is the only question this capability can settle. It does NOT answer 'may I write' — that is a permission on the actor, and a session can hold this capability and still be refused. Declared 2026-09-20 alongside github-api, on the owner's answer that the write path is several tools chosen by capability and permission.
