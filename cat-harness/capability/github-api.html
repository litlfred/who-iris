nameGitHub API (token or OAuth)
descriptionAbility to write to the forge over its HTTP API — create or update a file, open a pull request, comment — authenticated by a token or an OAuth grant rather than by holding a checkout. DISTINCT FROM git-push: this writes with no working tree, so it is the path available to a process that has a credential and no clone, and its reach is whatever the credential was granted rather than whatever the filesystem allows. Probed by CONFIGURATION, not by calling the API: a probe that issued a request would be indistinguishable from an outage or a rate limit, and would touch an external host to answer a question about local setup — the same reading deploy-access and signing-api take. Declared 2026-09-20 on the owner's answer that the write path is several tools chosen by capability and permission, not one design.
