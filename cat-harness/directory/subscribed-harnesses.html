titleSubscribed harness state
descriptionThe state directories of each harness this layer instantiates from a KG subscription: `<subscription>/<harness>/<state path>/`, one home per chosen harness, each state directory the harness declares created with a `.gitkeep`. Written by `bun run cat kg:instantiate`; the harness's processes write into it after that. Never at the repository root, where a harness named after a staged layer would write into that layer's directory (gap G11), and never under `subscriptions/`, which holds upstream's bytes and is read-only.
