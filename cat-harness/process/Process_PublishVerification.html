nameVerify the export before it is deployed
summaryRun the verifier set over the built tree between the export and the deploy, and report pass, fail or could-not-tell.
descriptionRun the verifier set over the built tree between the export and the deploy, and report pass, fail or could-not-tell. This process only verifies and says how it went. The caller (docs-site-publish) deploys either way, judges the outcome after the push, and routes anything but a pass through Process_PublishAlert, the one alert every failure shares.
