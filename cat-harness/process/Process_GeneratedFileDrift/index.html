nameCheck a generated file still matches its source
summaryCheck that a committed generated file still matches the source it is generated from.
descriptionCheck that a committed generated file still matches the source it is generated from. A GENERATED FILE THAT IS COMMITTED CAN GO STALE, AND A STALE ONE IS CONSULTED. The job reruns the generator in `--check` mode, which regenerates in memory and diffs against the committed file; any difference fails the job. Every drift check draws this same shape, so it is drawn once here (shared block G3 of the BPMN guidance review, owner Q-BR-2 C). Callers: jsonld-drift-check in cat-harness (the .jsonld siblings of the .ts manifests) and atomic-mass-drift-check in folio-assistant-sci (AtomicMass.lean from its data table). Each caller's call step says which generator runs; the caller's workflow keeps its own `# bpmn-node:` marker, so check:workflow-coverage still sees every job.
