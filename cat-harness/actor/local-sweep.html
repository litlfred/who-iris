descriptionThe same QA sweep programs as `ci-pipeline`, run on a contributor's or agent's machine rather than in CI. It runs a fixed program and exercises no judgement. It is a SEPARATE actor because the verdict it produces rests on a working tree nobody else can reconstruct: a CI verdict is reproducible from the commit it records, while a local one may rest on an uncommitted edit. Recording which one ruled is what keeps `reviewed_sha` an address rather than a decoration.
