titleTranslation refresh — the watcher
descriptionThe translation watcher: a scheduled fresh session that keeps every locale of every layer current after the source moves. Cold start, then, per layer, detect, refresh the templates, merge them into each locale, translate only the new and fuzzy strings with the fixed terms, run the gates, round-trip the changed strings, write the QA report, open one PR to main, merge it only where the layer declares merge-when-green, and report source mistakes as one issue. Use for "refresh the translations", "a template check failed", and when scheduling or running the watcher.
